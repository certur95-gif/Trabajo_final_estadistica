# Dengue and climate in Loreto, Peru (2017-2025)

Weekly dengue cases in Loreto (Peruvian Amazon) harmonized with climate data (temperature, humidity, precipitation) to model and forecast dengue using lagged climate variables and XGBoost in R.

## Data
- Dengue: public weekly aggregated cases by province (CDC Peru open data).
- Climate: temperature, relative humidity and precipitation (EDIT SOURCE).

## Methods
- Data cleaning and harmonization by epidemiological week
- Lagged climate predictors
- XGBoost model: training 2017-2023, validation 2024, test 2025
